# AirMouse

把 Android 手机变成一只**标准蓝牙鼠标**，用来控制平板、电脑或电视。

目标设备**不需要安装任何东西**——系统会把它识别成一个普通蓝牙鼠标。

## 功能

- **空鼠模式**：转动手腕控制指针，适合靠坐、远距离操作
- **触控板模式**：手机放桌上，手指滑动控制指针，像笔记本触摸板
- **完整鼠标按键**：左键、右键、中键、滚轮
- **两种拖拽方式**：双击拖拽（触摸板式）、按钮锁定（单手握持式），可分别开关
- **深色模式**：浅色 / 深色 / 跟随系统
- **桌面图标可换**：内置 6 套图标（G / I / K / G2 / I2 / K2），设置里点一下即时切换
- **参数可调**：手势时长、灵敏度、滚轮步长等全部可在 App 内实时调整并记住，不需要重新打包

## 界面原型

[`prototype/index.html`](prototype/index.html) 是 App 界面的 1:1 交互原型，用浏览器直接打开即可。
它可以点击、拖动、切换主题，用来在装机前确认交互。

改界面的流程：**先改原型，确认后再同步 Kotlin**。

## 构建

仓库自带 GitHub Actions，推送后自动编译并发布 APK：

1. push 到 `main`
2. Actions 自动运行 `Build APK`
3. 构建完成后在 [Releases](../../releases) 下载，文件名带版本号

版本号取自 `app/build.gradle.kts` 的 `versionName`，Release 会按 `v<版本号>` 打 tag。

本地构建需要 JDK 17 + Android SDK，直接：

```bash
./gradlew :app:assembleDebug
```

### 指针控制原理

用陀螺仪的**角速度**直接映射为指针**速度**（速率控制），而不是积分成角度再映射坐标。
后者会随漂移积累误差，十几秒就能偏到屏幕角落；速率控制在手机静止时指针立刻停下。

角速度先经旋转矢量投影到世界坐标系，因此手机以任意姿势握持都能正确对应屏幕方向。

HID 报告为 4 字节：按键位图 + X + Y + 滚轮，全部使用相对位移。

## 已知限制

- 需要设备支持 Bluetooth HID **Device** 角色（Android 9+ 的公开 API，但部分厂商可能未启用）
- 空鼠模式依赖陀螺仪
- Debug 签名，仅供个人使用
