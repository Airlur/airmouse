使用说明

可上下滑动 · 点空白处关闭
两种模式
空鼠：握着手机转手腕控制指针，适合靠坐、远距离。
触控板：手机放桌上，手指在白色区域滑动，像笔记本触摸板。
顶部状态胶囊
灰＝未注册，橙＝待配对，绿＝已连接。点它打开连接面板。
框选 / 拖拽（两种都支持）
双击拖拽：轻点一下 → 在设定时间内（默认 260ms）再按住并滑动 → 松手结束。适合手机放桌上。
按钮锁定：按住「左键」到设定时长（默认 400ms）变蓝锁定 → 滑动手腕或面板 → 再点一下释放。适合单手握机。
两者可以在设置里分别开关。
单击会不会变慢
不会。轻点立即发出左键，不等待双击判定。
触控板手势
单指滑＝移动指针；轻点＝左键；双击按住＝拖拽；长按＝右键；双指滑＝滚轮。
灵敏度 / 指针速度
空鼠模式的「灵敏度」是转手腕的放大倍数；触控板模式的「指针速度」是手指滑动的放大倍数。
水平 / 垂直反向
只影响空鼠模式。方向反了就打开，不用改代码。
滚轮区
上下滑动＝页面滚动；轻点＝中键单击。
设置按钮
齿轮图标里可以改主题、手势时长、拖拽方式开关、震动、常亮等，改完立即生效并记住。
